# 📊 Data Analytics Dashboard

## 🚀 Project Overview

## 🚀 Project Overview
This project is an interactive **E-Commerce Analytics Dashboard** built using Streamlit.

It allows users to:
- Filter customers by city, gender, and age
- Analyze revenue and order trends
- Understand customer behavior patterns
- Visualize insights using interactive charts
---

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* Plotly

## 📊 Features

### 1. KPI Metrics

* Total Customers
* Total Orders
* Total Revenue
* Returning Customer Rate

### 2. Sales Analysis

* Monthly Orders Trend
* Revenue by Category

### 3. Customer Insights

* Age Distribution
* Gender Split
* Top Cities

### 4. Buying Behavior

* New vs Returning Customers
* Purchase Frequency

### 5. Payment Analysis

* Payment Mode Distribution

### 6. Top Products

* Most ordered products

---

## ⚙️ How to Run

### Step 1: Clone Repository

git clone  https://github.com/hrudaymahajan/Data-Analytics-dashboard

### Step 2: Go to Folder

cd Data-Analytics-Dashboard

### Step 3: Install Requirements

pip install -r requirements.txt

### Step 4: Run App

streamlit run app.py

---

## 📌 Key Insights

* Returning customers generate higher revenue
* Certain categories dominate sales
* City-based trends affect order volume
* Digital payments are most used
